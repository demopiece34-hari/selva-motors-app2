# Selva Motors ERP

Google Sheet ONLY architecture.

## Flow
Page Open → Nothing Read → SHOW Button → Click → Full Screen HERO Loader → Read Required Google Sheet Only → Show Data

## Files
- app.py
- google_sheet.py
- pdf_generator.py
- ocr_module.py
- hero_loader.py
- utils.py
- assets/hero_logo.png

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
